# Mohit's Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript for a beginner web-development project.

## Files

- `index.html` — page structure and accessible content
- `style.css` — visual styling, layout, and responsive breakpoints
- `script.js` — mobile navigation, current footer year, and contact-form validation

## Run locally

Open `index.html` in a browser. No build tools or package installation are required. Google Fonts are loaded online; the site uses fallback fonts if they are unavailable.

## Personalize before submitting

1. Replace `your.email@example.com` in `index.html` with your real email address (update both the visible email and the `mailto:` link).
2. Review the bio and skills so they accurately describe you.
3. Replace the sample Task Tracker and Python Experiments entries with real projects, or label them clearly as ideas/in progress.
4. Test the page on desktop and mobile.
5. Upload all three code files and any added assets to a GitHub repository. Keep `index.html` at the repository root.
6. Enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)**.

## Rubric coverage

- HTML: semantic header, nav, main, sections, articles, form, and footer
- Accessibility: page language, descriptive title, skip link, accessible labels, form error/status announcements, keyboard focus styles, and meaningful image alternatives where images are added
- CSS: shared design system, typography, cards, layout, and consistent spacing
- JavaScript: responsive navigation toggle, footer year, and form validation
- Responsive design: tablet/mobile media queries and reduced-motion support

## Note about the contact form

The form validates user input in the browser only. It does not send, store, or email submissions. A real contact form needs a backend or a form service.
